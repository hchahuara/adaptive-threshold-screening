# Datasets

This directory is reserved for the datasets required to reproduce the experiments presented in the accompanying master's thesis.

Due to size and licensing constraints, **most datasets are not distributed with this repository** and must be obtained from their original sources. Some notebooks download the required data automatically, while others expect the datasets to be available locally.

## Dataset Sources

Used for the sparse image reconstruction experiments.

Download:
https://drive.google.com/drive/folders/1-Z5lq44F8QT76Uv_X-ZFZw5jBV1ivkAK?usp=sharing
